# 💪 Exercise Log — ตัวติดตามการออกกำลังกาย

WebApp ง่ายๆ สวยงาม ใช้งานบนมือถือ สำหรับติดตามการออกกำลังกายในแต่ละวัน
บันทึกทีละเซ็ต (เซ็ตละ 10 ครั้ง) จนครบเป้าหมาย 100 ครั้งต่อท่า

> เป็นไฟล์ HTML ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร — เปิด `index.html` บนมือถือหรือคอมพิวเตอร์ได้เลย

## ✨ ฟีเจอร์

- 📱 **Mobile-first** — ออกแบบสำหรับมือถือ แตะง่าย นิ้วโป้งเดียวใช้ได้
- ✅ **บันทึกทีละเซ็ต** — แตะ "＋ เพิ่ม 1 เซ็ต" หรือแตะจุดเซ็ตเพื่อบันทึก/แก้ไขได้อิสระ
- 🎯 **เป้าหมายปรับได้ต่อท่า** — ไม่ต้อง 100 ตายตัว พร้อมวงแหวนแสดงความคืบหน้าทั้งวัน
- 📐 **ขนาดเซ็ตกำหนดเองต่อท่า** — เช่น สควอทเซ็ตละ 20, วิดพื้นเซ็ตละ 10 (ค่าเริ่มต้น 10)
- 🧩 **โปรไฟล์ = ชุดท่ามาตรฐาน** — กำหนดได้ว่าในแต่ละวันมีท่าอะไรบ้าง
  - การแก้ไขโปรไฟล์มีผลกับ **ข้อมูลใหม่** เท่านั้น
  - วันที่บันทึกไปแล้วจะถูกเก็บเป็น snapshot ไว้ตามเดิม ไม่เปลี่ยนแปลง
- 🖼️ **รูปอ้างอิงต่อท่า** — แนบรูปได้ แสดง**แบบเต็ม**เมื่อแตะที่รูปย่อ ส่วน**แบบย่อ**แสดงชื่อ
- 📊 **สถิติ** — สตรีค 🔥 (ปัจจุบัน/สูงสุด), สรุป 7/30/90 วัน, กราฟแนวโน้มรายวัน, ปฏิทินความสม่ำเสมอ (heatmap)
- 📅 **ประวัติย้อนหลัง** — ดูและแก้ไขข้อมูลของวันไหนก็ได้
- 💾 **แก้ไขได้ตลอด + ส่งออก/นำเข้าไฟล์ .json** — สำรอง/กู้คืน/นำไปแก้ไขต่อได้
- 📲 **ติดตั้งเป็นแอปได้ (PWA)** — Add to Home Screen แล้วเปิดเต็มจอ ใช้งานออฟไลน์ได้

## 🚀 วิธีใช้

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ (มือถือหรือคอมฯ)
2. แท็บ **โปรไฟล์** → ตั้งค่าท่าออกกำลังกายของคุณ (ชื่อ / เป้าหมาย / รูป)
3. แท็บ **วันนี้** → แตะเพิ่มเซ็ตเมื่อออกกำลังกายเสร็จแต่ละรอบ
4. แท็บ **ประวัติ** → ดูย้อนหลังได้ทุกวัน

### แนะนำ: เพิ่มลงหน้าจอโฮม (มือถือ)
เปิดใน Safari/Chrome แล้วเลือก "Add to Home Screen" จะใช้เหมือนแอปจริง

## 🗂️ การเก็บข้อมูล

ข้อมูลเก็บไว้ใน `localStorage` ของเบราว์เซอร์บนเครื่องคุณเอง (ไม่ส่งขึ้นเซิร์ฟเวอร์)
ควรกด **ส่งออกข้อมูล** เป็นระยะเพื่อสำรองไฟล์ `.json` ไว้

## 🛠️ เทคโนโลยี

HTML + CSS + Vanilla JavaScript ล้วน ไม่มี dependency ภายนอก
(ฟอนต์ Noto Sans Thai จาก Google Fonts พร้อม fallback เป็นฟอนต์ระบบ)
